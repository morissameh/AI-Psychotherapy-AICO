🧠 AICO: Artificial Intelligence for psyChOtherapy

AICO is a demo mobile application designed to provide 24/7 psychotherapeutic support, making mental health resources more accessible, affordable, and stigma-free. The app uses the Falcon Large Language Model, fine-tuned with a diverse dataset of psychotherapeutic literature including cognitive behavioral therapy (CBT) techniques, motivational interviewing, and general mental health guidance.

AICO is built to simulate a therapeutic conversation, offering users a safe and empathetic space to express themselves, get emotional support, and receive AI-generated therapeutic suggestions — especially useful for individuals who may not have easy access to traditional therapy.

🌟 Key Features

24/7 Mental Health Support
Available anytime, anywhere to assist users struggling with stress, anxiety, or emotional challenges.

Natural Conversational Flow
Powered by Falcon LLM, offering responses that feel human-like, comforting, and personalized.

Modular Architecture
The app is built as a demo with independent modules — including:

Frontend (Dart via Android Studio)
Backend (Firebase for user data and storage)
Localhost API (Exposed using ngrok) for communication between the app and the LLM.
